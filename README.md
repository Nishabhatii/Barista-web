# ☕ Barista Web

A responsive and visually appealing café website built using **HTML, CSS, and JavaScript**.  
This project showcases a modern UI design suitable for coffee shops, cafés, or small food businesses.

## 🔗 Live Demo
👉 https://nishabhatii.github.io/Barista-web/

## ✨ Features
- Responsive design (mobile-friendly)
- Clean and modern UI
- Interactive navigation
- Smooth hover effects and animations
- Well-structured layout for café businesses

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript
